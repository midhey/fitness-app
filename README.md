# Домашняя форма

Нативное мобильное приложение для домашней программы тренировок. Сделано на React Native и Expo SDK 57, интерфейс — на русском.

В приложении есть:

- главный экран вокруг действия дня: полоса недели, все три силовые недели, комплексы и вес;
- 8-недельный план и три силовые тренировки в неделю;
- пошаговая тренировка: разминка → упражнения → итог, прошлый результат, подсказка «прибавь вес», автозаполнение подходов, ± подход, закреплённый таймер отдыха;
- таймер кардио на степпере, который переживает перезапуск и сбрасывается;
- ежедневный комплекс для осанки;
- вечерний комплекс «Спина, таз и шея» — план на неделю: у каждого дня свой набор из 7 упражнений в постоянном порядке задач (мобилизация → бёдра → корпус → ягодицы → шея → грудь и лопатки → расслабление), 23 упражнения, работа на шею каждый день;
- нативные анимированные схемы техники, траектории движения и подсветка работающих мышц;
- фазовые таймеры удержаний, повторов, дыхания, сторон и отдыха;
- прогресс: график веса по периодам, календарь занятий с журналом дня, графики рабочих весов;
- локальное хранение данных через AsyncStorage.

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm start
```

После запуска можно открыть проект в Expo Go по QR-коду. Для локальной нативной сборки:

```bash
npm run ios
npm run android
```

`ios` требует macOS и Xcode, `android` — Android Studio и настроенный Android SDK.

## Проверка

```bash
npm run typecheck

```

## Сборка установочного приложения

Профили сборки описаны в `eas.json`. APK для установки на Android напрямую:

```bash
npx eas-cli build --platform android --profile preview
```

Сборка для магазинов — профиль `production` (Android App Bundle и iOS).

Идентификаторы приложения задаются в `app.json`: `app.homefit.mobile` для Android и iOS.

## Данные

Данные сохраняются только на устройстве под ключом `homefit.v1`. После успешной записи приложение обновляет внутреннюю резервную копию и хранит семь дневных снимков. Из профиля копию можно экспортировать в JSON через системное меню и затем восстановить; внешний файл переживает удаление приложения, если сохранить его в «Файлы» или Downloads.

Если основное хранилище повреждено, приложение сохраняет исходную строку под ключом `homefit.v1.corrupt.<время>` и пробует восстановить последнюю исправную внутреннюю копию. При ошибке чтения запись блокируется до повтора. Браузерный `localStorage` из старой PWA автоматически перенести нельзя: мобильное приложение работает в отдельном системном хранилище.

## Структура

```text
app/                 маршруты и нативные экраны Expo Router
src/native/          тема (Onest, палитра), UI-компоненты, графики, календарь, таймеры
src/store/           состояние и AsyncStorage
src/data/            программа тренировок и комплексы (back.ts — недельный план «Спина, таз и шея»)
src/lib/date.ts      работа с датами
src/types.ts         типы предметной области
assets/              иконка, splash screen и звук сигнала
```

Приложение не ставит диагнозов и не лечит. При боли, онемении, покалывании или слабости нужна очная оценка врача или физиотерапевта.
