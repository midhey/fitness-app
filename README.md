# Домашняя форма

Мобильное веб-приложение (React + TypeScript + Tailwind CSS) для домашней программы:
3 силовые тренировки в неделю с гантелями, умеренное кардио на степпере,
ежедневный комплекс для осанки и дневник прогресса. Интерфейс на русском, тёмная тема,
данные хранятся в `localStorage` браузера.

Программа тренировок и структура экранов описаны в [DESIGN.md](DESIGN.md).

## Запуск

Нужен Node.js 20+ (в этой системе — `C:\Users\Semenov910268\AppData\Local\nvm\v22.22.2\node.exe`;
по умолчанию nvm указывает на Node 14, на нём сборка не работает).

```powershell
$node = "C:\Users\Semenov910268\AppData\Local\nvm\v22.22.2\node.exe"

# разработка: http://localhost:5173 (и адрес в локальной сети — для телефона)
& $node node_modules/vite/bin/vite.js --host

# проверка типов и сборка в папку dist/
& $node node_modules/typescript/bin/tsc --noEmit
& $node node_modules/vite/bin/vite.js build

# просмотр собранной версии
& $node node_modules/vite/bin/vite.js preview --host
```

Если в `PATH` уже Node 20+, работают и обычные `npm run dev`, `npm run build`, `npm run preview`.

## Установка на Android

Для установки нужен адрес с HTTPS. Проще всего — GitHub Pages: в репозитории уже есть
workflow `.github/workflows/deploy.yml`, который собирает и публикует приложение при каждом push в `main`.

1. Создайте пустой репозиторий на GitHub (можно приватный — Pages для приватных репозиториев
   доступен на платных планах; для бесплатного аккаунта репозиторий должен быть публичным).
2. Привяжите и отправьте код:
   `git remote add origin https://github.com/<логин>/<репозиторий>.git` и `git push -u origin main`.
3. На GitHub: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
   Если первый запуск workflow упал до этой настройки — перезапустите его во вкладке Actions.
4. Через 1–2 минуты приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.
5. Откройте адрес в Chrome на телефоне → меню ⋮ → «Установить приложение»
   (или «Добавить на главный экран»). Появится иконка, приложение откроется без адресной строки
   и после первой загрузки будет работать без интернета.

Сборка использует относительные пути, поэтому так же работает на Netlify, Cloudflare Pages
или любом статическом хостинге — достаточно выложить папку `dist/`.

Быстрая проверка без публикации: запустите `vite preview --host` на компьютере и откройте показанный
«Network»-адрес на телефоне в той же Wi-Fi-сети. Работает всё, кроме установки и офлайн-режима (нужен HTTPS).

Данные на телефоне хранятся отдельно от компьютера — это разные браузеры.

## Данные

- Всё хранится только в этом браузере: ключи `homefit.v1` (профиль, вес, журнал, осанка,
  незавершённая тренировка) и `homefit.cardioTimer` (идущий таймер кардио).
- Очистка данных сайта в браузере удаляет историю. Сброс вручную — в профиле (кнопка в правом верхнем углу главного экрана).

## Структура

```
src/
  data/           программа: упражнения, тренировки A/B/C, 8 недель, кардио, комплекс для осанки
  illustrations/  движок схематичных SVG-анимаций: скелет (rig), отрисовка (draw), позы (library)
  screens/        Главная, План, Тренировка, Кардио, Осанка, Комплекс, Прогресс
  components/     UI-кит, шторки, таймеры, графики, календари
  store/          состояние и сохранение в localStorage
  lib/            даты, маршрутизация с кнопкой «Назад» Android, звук/вибрация, wake lock
public/           манифест, иконки, service worker
```

## Иллюстрации

Фото и видео техники в проекте нет. Вместо них — схематичные анимации собственного движка:
исходное и конечное положение, траектория движения и подсветка работающих мышц.
Они подписаны «Схема» и не заменяют разбор техники с тренером.

## Важно

Приложение не ставит диагнозов и не лечит. При выраженном искривлении, боли, онемении,
покалывании или слабости в руках и ногах нужна очная оценка врача или физиотерапевта
(предупреждение есть на экране «Осанка»).
