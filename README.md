# Домашняя форма

Нативное мобильное приложение для домашней программы тренировок. Сделано на React Native и Expo SDK 57, интерфейс — на русском.

В приложении есть:

- 8-недельный план и три силовые тренировки в неделю;
- журнал подходов с подстановкой последних рабочих весов;
- таймер кардио на степпере;
- ежедневный комплекс для осанки и комплекс «Спина и таз»;
- нативные анимированные схемы техники, траектории движения и подсветка работающих мышц;
- фазовые таймеры удержаний, повторов, дыхания, сторон и отдыха;
- история веса, тренировок и кардио;
- локальное хранение данных через AsyncStorage.

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm start
```

После запуска можно открыть проект в Expo Go по QR-коду. Для локальной нативной сборки:

```bash
npm run ios
npm run android
```

`ios` требует macOS и Xcode, `android` — Android Studio и настроенный Android SDK.

## Проверка

```bash
npm run typecheck
npm run doctor
```

## Сборка установочного приложения

Для облачной сборки через EAS:

```bash
npx eas-cli build:configure
npx eas-cli build --platform android
# или
npx eas-cli build --platform ios
```

Идентификаторы приложения задаются в `app.json`: `app.homefit.mobile` для Android и iOS.

## Данные

Данные сохраняются только на устройстве под ключом `homefit.v1`. Браузерный `localStorage` из старой PWA автоматически перенести нельзя: мобильное приложение работает в отдельном системном хранилище.

## Структура

```text
app/                 маршруты и нативные экраны Expo Router
src/native/          тема и UI-компоненты React Native
src/store/           состояние и AsyncStorage
src/data/            программа тренировок и комплексы
src/lib/date.ts      работа с датами
src/types.ts         типы предметной области
public/              иконка приложения и splash screen
```

Приложение не ставит диагнозов и не лечит. При боли, онемении, покалывании или слабости нужна очная оценка врача или физиотерапевта.
